# FEMINELLA Online Store

Static storefront for GitHub Pages.

## Important
Before sharing the live website, open `config.js` and replace:
`919999999999`
with your WhatsApp Business number in international format, without `+`, spaces or leading zero.

Example: `919876543210`

## Publish
Upload the contents of this folder (not the ZIP itself) to a GitHub repository.
Enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

The website entry file is `index.html`.
